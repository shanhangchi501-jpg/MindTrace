# 心迹 0.1.0

首个可测试版本：一款完全离线、加密保存在本机的精神健康自我记录工具。

## 包含

- 每日打卡：情绪、焦虑、睡眠、症状、诱因、用药与备注
- 药物管理与服药打卡、每日提醒
- PHQ-9 / GAD-7 自评
- 7/30/90 天趋势
- 本地生成的复诊 PDF 与 CSV 导出
- 安全计划、危机资源与紧急支持
- 加密备份与恢复
- 应用锁、防截屏、通知脱敏

## 隐私

- 不申请 INTERNET 权限
- SQLCipher 全库加密，密钥由 Android Keystore 包裹
- 无账号、无广告、无统计 SDK、无云同步

## 注意

心迹不是医疗器械，不提供诊断或治疗建议。紧急情况请联系 120 / 110 或心理援助热线 12356。

这是早期测试版本，功能和文案仍可能调整。请先导出备份再测试删除全部数据。
