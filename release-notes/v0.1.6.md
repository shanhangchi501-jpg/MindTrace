# 心迹 0.1.6

## 中英文模式

设置内新增「语言」，可选择「跟随系统 / 中文 / English」，切换后立即生效，不需要重启。

英文模式覆盖界面、日期、星期、问候语、通知、症状、诱因、量表题目与分级建议、安全计划、CSV 和复诊 PDF。用户自己填写的姓名、日记、药名和备注不会被翻译。

## 诊断记录

新增「设置 → 诊断记录」：

- 按 ICD-10 / ICD-11 常用条目搜索编码、中文名或英文名
- 记录状态：已确诊 / 疑似 / 已缓解 / 既往诊断
- 可填写确诊日期、医生 / 机构和备注
- 找不到条目时可自定义名称与编码
- 诊断会写入加密备份与复诊 PDF

这里只保存使用者已经得到的诊断，不根据打卡内容自动下诊断。

## PDF 预览与观感

- 复诊报告页新增「预览 PDF」，可在应用内逐页查看后再保存或分享
- PDF 版式重做：封面区、指标卡片、分区标题、趋势图面积填充、页眉页脚与页码
- PDF 使用当前界面语言生成

## 其它

- 移除页面切换的淡入淡出动画，切换即时完成
- 数据库升级到 schema v2，提供 1→2 迁移
- 备份格式向后兼容，新增诊断字段
- 新增诊断目录与英文动态文案的单元测试

## 升级

直接覆盖安装即可，旧数据会通过数据库迁移保留。卸载或更换手机前，请先导出加密备份。
