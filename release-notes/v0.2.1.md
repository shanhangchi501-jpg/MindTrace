# 心迹 0.2.1

这一版重做了「科普」的内容结构与阅读体验：只保留疾病、症状、药物三类，修好了 Markdown 表格，并把药物扩展到 102 条。

## 词条只保留三类

| 分类 | 条数 | 来源 |
| --- | ---: | --- |
| 疾病 | 127 | 多意识体系统 Wiki |
| 症状 | 23 | 多意识体系统 Wiki |
| 药物 | 102 | 维基百科 |

移除了「多意识体」「治疗与支持」「理论与文化」三个分类。原来的治疗、理论与社群概念不再混在疾病列表里，查找更直接。

## 药物覆盖

药物条目从 16 条扩展到 **102 条**，覆盖：

- SSRIs、SNRIs、其他抗抑郁药、三环类、MAOIs
- 典型与非典型抗精神病药
- 心境稳定剂
- 苯二氮䓬类、Z 类药物、非苯二氮䓬类抗焦虑药
- ADHD 兴奋剂与非兴奋剂
- 痴呆用药
- 阿片类替代治疗、戒烟与酒精使用障碍用药
- 氯胺酮 / 艾氯胺酮、褪黑素、迟发性运动障碍治疗药

每条药物现在包含：

- **快速了解**表格：药物类别、主要用途、需要关注
- **类别说明**：这一类药物的共同机制与使用背景
- **概述**：中英文维基百科导言
- **同类药物**：同一类别的其他药物，方便对照
- **用药提醒**：按类别整理的安全提醒

中文维基条目暂缺的 23 个药物也补充了较完整的中文说明，不再只有一两句话。安全提醒只用于健康教育，不构成剂量、处方或停药建议。

## 精神分裂症谱系：阳性 / 阴性症状与强度滑块

症状目录新增：

- **阳性症状**：幻觉、妄想、多疑 / 被针对感、思维紊乱 / 言语散乱、行为紊乱、紧张症表现、被控制感 / 思维被洞悉
- **阴性症状**：情感平淡、言语贫乏、意志减退、个人卫生下降

「我的资料 → 关注方向」新增 **精神分裂症谱系**。选择后会自动启用这些症状；已有用户下次打开应用时，这些症状也会出现在症状设置中。

如果关注方向包含「精神分裂症谱系」或「精神病性体验」，打卡页会为每个已选症状显示 **0–10 强度滑块**。强度会随当天记录保存，并显示在首页、日期详情和 CSV 导出中。

趋势页新增 **症状强度折线图**。有强度记录的症状会显示为可切换的标签；选中后可以查看该症状在 7/14/30/90 天内的 0–10 强度变化。没有记录强度、但当天有记录且没有勾选该症状时按 0 显示；完全没有记录的日子留空，不会被误当成 0。

复诊 PDF 也会同步：

- 趋势区新增 **症状强度折线图**，默认展示记录最多的有强度症状（例如「症状强度 · 幻觉（0–10）」），并按所选日期范围绘制
- 「症状频率与平均强度」部分列出每种症状的出现天数与平均强度，例如「幻觉 2天 · 5.0/10」

旧记录仍可正常读取，数据库会从 v2 自动迁移到 v3。

## 定时用药改成一个按钮

首页和药物页的定时用药现在只有一个切换按钮：

- 未记录时显示「服用」
- 点一下变成「已服」
- 再点「已服」回到「服用」，用于误点或撤销
- 不再有单独的「跳过」「撤销」按钮
- 过去日期的未记录剂量仍显示「补记」

依从率不再把历史「跳过」记录计入分母。

## 表格终于能正常看了

之前部分 Wiki 页面里的 Markdown 表格被压成用 `｜` 分隔的文本行。现在正文在构建时被解析成结构化块：

- 表头有独立底色
- 每一行有分隔线
- 单元格自动换行
- 宽表格可以左右滑动
- 详情页会提示「表格内容可以左右滑动查看」

同时修复了提示框与正文粘连、列表被合并、脚注残留等问题。

## 二级详情页

列表仍然只显示标题、分类、来源与摘要。点击任意条目进入独立详情页，可以阅读全文、长按选择复制，并看到来源、许可证与更新时间。

英文界面下：

- 药物条目显示英文正文
- Wiki 条目标题显示英文名，正文保留中文，并显示「Chinese only」提示
