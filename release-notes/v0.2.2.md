# 心迹 0.2.2

这一版重排了复诊 PDF，让每种症状的强度变化都能被医生看到，同时压缩诊断、用药和量表，给折线图腾出空间。

## 每种症状都有自己的折线图

之前 PDF 只展示记录最多的一种症状。现在只要症状填写过 0–10 强度，就会生成一张独立的折线图：

- 按 3 列排列，标题显示症状名与出现天数，例如「幻觉 · 23天」
- 实线是每日强度，虚线是该症状的平均强度
- 虚线旁标出具体数值，例如「均 4.6」
- 没有打卡的日子留空，折线在该处断开
- 有记录、但当天没有勾选该症状时按 0 显示

原来的「症状频率与平均强度」条形表已移除，空间全部让给症状图。

## 压缩版式，11 张图在一页内

- **诊断记录**：每条压缩成一行，名称、编码、标准、日期、医生与状态同排显示，高度约为原来的一半
- **用药与自评量表**：改为左右并列的两栏，各显示最近 3 项，超出部分标注「另有 N 项」
- 首屏最多容纳 **11 张**症状折线图
- 第 12 张起自动续到第 2 页，并显示「症状强度（续）」；用药、量表、安全记录与说明顺延
- 问题、安全记录与说明在空间不足时也会自动续页，不会被页脚裁切

日记摘录仍然只在勾选且范围内有日记时追加；如果已经产生症状续页，日记页顺延到后面。
