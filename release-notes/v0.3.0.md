# 心迹 0.3.0

这一版把复诊 PDF 分成两种版式由用户自己选择，并让症状强度滑块不再依赖病种。

## 报告版本由你选择

在「生成复诊报告 → 报告版本」中可以选择：

### 医生详细版（默认）

- 第 1 页：基本信息、记录完整性、摘要、诊断、目前用药、安全相关记录与想讨论的问题
- 第 2 页：症状概览表、用药明细、自评量表与报告说明
- 后续页面：**2 列大图**症状折线图，每页最多 6 张
- 每张图包含每日强度实线、平均强度虚线与「均 N.N」标注
- 字号、图表尺寸与分页都以打印和医生阅读为目标

### 一页摘要

- 通常 1 页，3 列紧凑症状图
- 适合自己留存或快速分享
- 超过 11 张症状图时自动续页

选择会用于预览、保存和分享；详细版样例为 4 页，摘要版为 1 页。

### 修复

- 修复在 PDF 预览窗口里点「保存 PDF」只关闭预览、不打开系统保存界面的问题
- 预览窗口底部的保存 / 分享按钮上移，避开手势导航区域

## 症状强度滑块不再要求病种

之前只有选择「精神分裂症谱系」或「精神病性体验」才会出现强度滑块。现在：

- 勾选任意症状后，打卡页底部都会出现「症状强度（可选）」
- 默认显示「未评分」，只有拖动滑块才写入强度
- 点「清除」可恢复为未评分
- 0 = 没有 / 几乎不影响，10 = 极重 / 严重影响
- 首页、日期详情、趋势、CSV 与 PDF 都会使用这些强度

这样既保留了精神分裂症谱系的阳性 / 阴性症状体验，也让抑郁、焦虑、创伤等其他症状可以记录强度。

## 仍然离线

应用不申请 `INTERNET` 权限。PDF、CSV 与备份都在本机生成，由你决定保存或分享。PDF 与 CSV 是未加密的明文文件，分享前请确认接收对象。

- 0.2.x 的备份格式仍可用于 0.3.0
