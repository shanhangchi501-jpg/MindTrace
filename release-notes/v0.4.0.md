# MindTrace 0.4.0 发布说明 / Release Notes

发布日期：2026-11-13

## 中文

### 主题与外观
- 新增 5 套主题色（青绿 / 海蓝 / 梅紫 / 琥珀 / 玫瑰），浅色 / 深色 / 跟随系统全部可用
- 全新毛玻璃卡片 + 极光渐变背景 + 柔和光影；修复深色方块阴影、过重光晕影响阅读的问题
- 「补充记录 / 服药打卡 / 自评量表」等快捷卡片统一为玻璃卡片风格

### 首页与记录
- 首页「今天的用药」完整展示全部剂量，不再省略或折叠
- 趋势页统计卡排版修复（记录天数不再折行/省略）
- 图表空状态、坐标与说明文字跟随界面语言

### 药物
- 每种药物每日服药时间可添加多次，取消原先 2 次上限
- 在服药物支持**长按拖动排序**：跟手阈值、换位动画、松手弹性归位，顺序持久化
- 添加药物时输入名称会弹出**中英双语通用名候选列表**（281 条预设，覆盖精神科与常用非精神科药物；只写通用名、不区分剂型）
- 药物名称随界面语言切换（Sertraline ↔ 舍曲林），编辑页同样本地化

### 科普与双语
- 150 条疾病 / 症状科普全部补齐英文正文与英文描述；科普库 252 条现已全部具备英文内容
- 保留原有块结构（标题、段落、列表、表格、提示框、参考文献），表格与 FAQ 可正常渲染
- 新增 18 条双语症状科普（症状分类 23 → 41 条）
- 修复英文模式下设置页、趋势页、底部导航、药物名、个人页关注方向等位置的中文残留

### 导航与性能
- 底部 5 个标签改为**常驻组合**：切换时不再重建页面，无淡入淡出重影、无空白帧，滚动位置保留
- 导航文案单行显示（Meds / Trends / Learn / Me）

### 安全与紧急支持
- 紧急支持页新增**国家/地区选项**（中国大陆、港澳台、美国、加拿大、英国、爱尔兰、德国、法国、澳大利亚、新西兰、日本、韩国、新加坡、印度、欧盟/其他），急救、报警与心理援助热线随地区切换并持久化
- 同一号码不再重复显示（如美国 911）

### 关于作者与赞助
- 设置新增「赞助与作者的话」页：爱发电按钮调用系统浏览器打开 `https://ifdian.net/a/Hi-res`，并提供复制链接
- 作者的话（中英双语）按原稿上线
- 首次设置流程新增「作者的话」页（5/5）
- 第 5 次启动时弹窗提示，可选择去赞助或以后再说，只提示一次

### 修复
- 提醒权限按钮文字过长导致竖排换行
- 设置页部分分节标题中英混排
- 趋势折线图空状态文字未翻译
- 个人资料关注方向拼接后无法翻译
- 编辑药物时名称未本地化

### 已知问题
- 药物条目（drug_*）的英文块数与中文块数存在历史差异，本次未改动该数据
- 少量科普条目因源文件断行，英文列表项数量比中文少 1 项（内容完整）

## English

### Theme & visuals
- 5 accent palettes (Sage / Ocean / Plum / Amber / Rose) with light, dark and system modes
- New frosted-glass cards, aurora gradient background and softer glow; fixed rectangular shadow artifacts

### Record & trends
- Home shows all of today's doses (no truncation)
- Fixed trend stat tile layout and translated chart empty states

### Medication
- Multiple daily dose times per medication (no 2-time cap)
- Long-press drag reordering with animated placement and spring settle, persisted
- Bilingual generic-name dropdown with 281 presets (psychiatric and common general medicine; dosage forms ignored)
- Medication names follow the UI language, including the edit screen

### Education & i18n
- All 150 disease/symptom wiki entries now have English bodies and descriptions (all 252 entries have English content)
- 18 new bilingual symptom entries (symptom category 23 → 41)
- Fixed leftover Chinese in settings, trends, bottom navigation, medication names and profile labels

### Navigation & performance
- Bottom tabs are kept composed: instant switching with no cross-fade ghosting or blank frames, scroll positions preserved

### Crisis support
- Region selector with 18 regions; emergency, police and mental-health hotline numbers follow the selected region and are persisted

### Author & sponsorship
- New "Sponsor & author's note" page opening Afdian in the system browser, with copy-link fallback
- Author's note (Chinese/English); shown as the final onboarding page and a one-time 5th-launch prompt
